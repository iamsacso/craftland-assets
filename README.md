# Craftland Assets

Website: https://iamsacso.github.io/craftland-assets/

Download Craftland studio packages — models, characters, custom objects, ECA scripts, UI, sound, particle emitters, and more.

## Run locally

```
npm install
npm start
```

Open http://localhost:4173

Upload packages at `admin.html`. Default admin key: `craftland` (change it in `.env`). After uploading, push to GitHub so the live site updates.

## Sections

Model, Characters, Custom Object, ECA Script, UI, Sound, Particle Emitter, Others.
